1. ЧТО ЭТО ЗА ПРОДУКТ
--------------------------------------------------------------------------------

Life OS — веб-приложение «операционная система жизни»: трекер привычек, целей,
квест-контрактов, планировщика задач, рабочего стола с виджетами/мудбордом,
колеса баланса («Карта жизни») и аналитики прогресса.

Центральная метафора:
- привычки = ежедневные отметки (completions по датам);
- цели = измеримый результат + связанные привычки;
- квесты = платные контракты (алмазы), порождающие привычку/список пунктов;
- алмазы = внутренняя валюта (мягкий лимит на перегрузку);
- Pro-подписка = булевый флаг (без реальной оплаты), открывает Цели / Квесты / Карту жизни.

Всё состояние пользователя хранится в localStorage браузера. Сервера, БД,
настоящих платежей и URL-роутинга нет.

5. АВТОРИЗАЦИЯ И РЕГИСТРАЦИЯ (ОТ ВХОДА ДО СЕССИИ)
--------------------------------------------------------------------------------

Файл: src/lib/auth.ts
Хук:  src/hooks/useAuth.ts
UI:   src/pages/AuthPage.tsx

Ключи localStorage:
  life-os-auth-users   — массив AuthUser
  life-os-auth-session — строка userId или отсутствует

Тип AuthUser:
  id, name, email, passwordHash, createdAt,
  hasSubscription: boolean,
  lifeMapOfferStatus: 'pending' | 'accepted' | 'deferred' | 'done',
  trainingPhase?: TrainingPhase

TrainingPhase:
  'offer' | 'free_tour' | 'wheel_offer' | 'pro_offer' | 'pro_tour'
  | 'completed' | 'skipped'

PublicUser = AuthUser без passwordHash.

--- Функции auth.ts ---

readSessionUserId()
  Читает SESSION_KEY из localStorage.

hashPassword(password)
  SHA-256 от строки `life-os:{password}` через crypto.subtle.
  Возвращает hex-строку. (Локальный тест, НЕ для продакшена.)

ensureOwnerAccount()
  Если нет пользователя artem@lifeos.app — создаёт владельца:
    id: u-owner-artem
    name: Артём
    password: artem123
    hasSubscription: false
    trainingPhase: 'completed'
    lifeMapOfferStatus: 'pending'
  Вызывается при регистрации/логине и при монтировании AuthPage.

getSessionUser()
  По session id находит пользователя в списке → PublicUser | null.

getCurrentUserName(fallback='Гость')
  Имя текущего пользователя или fallback.

isTesterUser(user)
  true, если user.id === 'u-owner-artem' (TESTER_USER_ID).

avatarLetter(name)
  Первая буква имени в верхнем регистре или '?'.

registerUser({ name, email, password })
  Валидация:
    имя ≥ 2 символов
    email по regex
    пароль ≥ 6 символов
    email не занят
  Создаёт пользователя:
    id: `u-${Date.now()}`
    hasSubscription: false
    lifeMapOfferStatus: 'pending'
    trainingPhase: 'offer'
  Пишет в users, ставит session, возвращает { ok: true, user }.

loginUser({ email, password })
  Ищет по email (lower), сверяет hashPassword.
  При успехе пишет session.

logoutUser()
  Удаляет session key.

purchaseSubscription(userId)
  updateUser → hasSubscription: true. Оплаты нет.

setLifeMapOfferStatus(userId, status)
  Обновляет lifeMapOfferStatus.

setTrainingPhase(userId, trainingPhase)
  Обновляет trainingPhase.

--- useAuth() API ---

  user, isAuthenticated, hasSubscription
  register(), login(), logout()
  buySubscription()
  setLifeMapOffer(status)
  setTraining(phase)
  refresh()

--- AuthPage UI ---

Режимы: register | login.
Поля: имя (только register), email, пароль.
Кнопки переключения режима.
onRegistered() вызывается после успешной регистрации → App ставит
justRegistered и page='dashboard', открывает TrainingOfferModal.

OWNER demo: artem@lifeos.app / artem123 (создаётся автоматически).

6. ПОСТ-РЕГИСТРАЦИОННЫЙ ОНБОРДИНГ (ОБУЧЕНИЕ)
--------------------------------------------------------------------------------

Оркестрация: App.tsx + data/tour.ts + модалки.

Поток фаз:
  1) offer          → TrainingOfferModal («пройти обучение?» / пропустить)
  2) free_tour     → TourOverlay(FREE_TOUR_STEPS) по бесплатным разделам
  3) wheel_offer    → BalanceWheelOfferModal (создать колесо / купить Pro / отложить)
  4) pro_offer      → ProTourOfferModal (если есть подписка)
  5) pro_tour      → TourOverlay(PRO_TOUR_STEPS)
  6) completed | skipped

Обработчики App.tsx:
  startFreeTour / skipTraining
  completeFreeTour / skipFreeTour → wheel_offer
  createWheel(addToMoodboard) → createLifeMap(), опционально placeLifeMapOnMoodboard,
                                page=life-map, training=pro_offer
  buyAndCreateWheel → buySubscription + createWheel
  deferWheel → lifeMapOffer=deferred; если Pro — pro_offer, иначе completed
  startProTour / skipProTour / completeProTour
  buySubscription — из AccountPanel / paywall; может открыть Pro-тур
  restartTraining — снова offer из AccountPanel

TourAction: 'go' | 'click' | 'next' | 'done'
TourStep: id, page, target (data-tour атрибут или 'center'), title, body, cta, action

FREE_TOUR_STEPS (кратко):
  welcome → nav dashboard → desktop (add widget) → planner (add task) →
  calendar tip → habits (add) → progress / economy → done

PRO_TOUR_STEPS (кратко):
  life-map / wheel → goals (new + matrix) → quests (create) → связи сущностей → done

defaultTrainingPhase(undefined) → 'completed' (старые аккаунты без обучения).

   Привычки → Прогресс/экономика.
6. Пользователь создаёт привычку (−10💎), отмечает дни (+5💎/день).
7. Планировщик: задачи → привычки; календарь для расписания.
8. Дашборд показывает next quest, прогресс дня, предупреждения.
9. Оффер колеса: создать карту жизни (Pro) / купить подписку / отложить.
10. Pro: карта жизни (привычки по секторам за 5💎), цели (15💎), матрица (20💎),
    квесты (20/30/50💎, награда ×2 при победе).
11. Pro-тур объясняет связи сущностей.
12. Прогресс-вкладка: графики месяца, инсайты, история алмазов.
13. Visit streak 7 дней → +50💎.
14. Logout очищает session; данные store остаются в localStorage по userId.

22. ПРАВИЛА И ИНВАРИАНТЫ ДОМЕНА
--------------------------------------------------------------------------------

- Будущие дни отмечать нельзя.
- Пропуск продлевает effectiveEndDate (countMisses).
- Привычка «сформирована» при completedCount >= targetDays → больше не due.
- Макс. 8 привычек на аспект карты жизни.
- Системные life-map цели нельзя удалить как обычные.
- Квест settled: won → награда один раз; lost по deadline; abandon без награды.
- Sale claim нельзя получить дважды (claimedSaleIds).
- Ретро: 5/месяц, потом блок 30 дней.
- Pro — только UI-гейт; данные goals/quests/life-map всё равно могут быть
  в store, но страницы закрыты paywall.
- Нет синхронизации между устройствами / браузерами.
